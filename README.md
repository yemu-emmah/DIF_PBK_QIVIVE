PBK-facilitated QIVIVE for plant protection products (PPPs)

Layout:

•	PBK model files are under model:

o	Rat oral difenoconazole model (DIF_oral_0.5_rat.R)

o	Human oral difenoconazole model (DIF_oral_0.5_human.R)

o	Human dermal difenoconazole model (DIF_oral_CLdermalexp_human.R)

o	Human dermal formulated product model (PPP_oral_CLdermalexp_human.R)

•	Custom QIVIVE and uncertainty code files for the formulated product are under script:

o	QIVIVE (PPP_IVIVE.R)

o	Uncertainty analysis (uncertainty_analysis_PPP.R)

o	Model convergence (MCMC_convergence.R)
